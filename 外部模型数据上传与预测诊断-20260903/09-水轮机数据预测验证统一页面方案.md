# 水轮机数据、预测与验证统一页面方案

> 日期：2026-09-09
> 范围：sim-visual-hydro-turbine，模型 2326。
> 状态：已随 Release 20260909-121745 发布，并通过服务器预检和公网浏览器验收。
> 本文替代 08 号文档中固定 50 组目录、两套上传和独立验证工作台的页面方案。既有数据和已完成核验记录需保留。

## 1. 目标与统一业务流程

以“当前设备、当前数据组”为整页唯一工作上下文。数据管理、历史展示、预测、后续实测核验属于同一流程，不再拥有各自独立的上传入口、设备选择和历史图。

流程：统一传入数据 → 确认归属与增加/覆盖方式 → 保存并选中本次数据组 → 查看历史与生成预测 → 传入后续实测并匹配本次预测 → 查看当前核验结果 → 更新累计统计。

50 组只是已准备的样例数量，不是产品限制、预置设备目录或进度分母。不得预列 HT-01～HT-50、展示“0/50”，也不得以固定样例组号限制真实数据。

## 2. 设备、批次与当前数据组

- 设备 ID 表示具体设备；一台设备可以有多个传入批次和多次预测。
- 传入批次记录一次导入的来源、时间、记录数量和质量情况。
- 当前数据组是用户从已保存数据中选择的一份预测参考数据，具有明确设备、时间范围和数据版本。可选择某次批次，也可明确选择该设备合并后的数据范围。
- 默认选中刚成功导入的设备和本次数据组。若用户选择以合并后的历史作为参考，则整页切换到该合并范围，界面必须明确显示时间范围与记录数。
- 选择数据组时，实测数值、历史曲线、预测曲线、结论、预警部位和当前验证结果同步变化。不能残留上一个设备或上一组预测结果。
- 不把多台设备的记录合成同一条时间序列。设备名称相同不能代替设备 ID 判断。

## 3. 统一上传入口

整页保留一个“传入数据”入口，使用同一弹窗、进度条、格式识别、协议映射、异常预检和确认流程。

弹窗中先选择用途：“历史运行数据”或“后续实测验证”。这是同一个入口的两种业务用途，不再提供独立的“预测历史上传”模块。

### 历史运行数据

确认导入前必须明确数据归属：

1. 合并到已有设备：用下拉框选择设备，选择增加数据或覆盖该设备已有数据。
2. 新建一个设备保存：输入新设备 ID，重复 ID 不允许作为新设备创建。

增加数据保留此前记录，按明确的时间冲突规则处理重复点；覆盖替换确认范围内的原记录。界面预检需显示目标设备、新旧时间范围、增加/替换/冲突条数。覆盖只确认一次，可取消。

文件内设备 ID 与所选归属不一致时明确提示，由用户确认映射或返回选择，不能静默混入其他设备。

保存成功后，页面自动定位刚导入的数据组；各历史展示区域同步到该组。增加不代表丢弃此前存储数据，覆盖不代表继续在当前历史图中混用被覆盖记录。

预测从已入库数据产生，无需重复上传相同历史文件。可以在导入成功后接续生成预测，也可以稍后从已保存的数据组中选择并生成。

### 后续实测验证

默认关联当前数据组已经生成的预测，弹窗显示设备、预测生成时间和目标预测区间，避免错配。

先形成并保存预测快照，再接收后续实测进行核验。验证数值、实际标签和故障信息不能参与原预测拟合或修改原预测结论。

按设备和时间对齐；不重叠的验证数据不能产生有效误差。只覆盖部分预测区间时显示核验覆盖率与“部分核验”，不按完整核验统计。没有实际标签可计算数值误差，但不能计入状态准确率；缺少故障结论依据时不能计入故障类型准确率。

后续实测可保存为同一设备的后续数据批次，但原预测参考范围与快照保持不变。若用户要基于新增实测重新预测，应明确生成新预测，不能覆盖正在核验的原预测。

## 4. 页面布局

```text
页面标题、模型与业务说明
┌─────────────────────────────────────────────────────────┐
│ 当前设备 [选择]  参考数据组 [选择]  时间范围 / 记录数        │
│ [传入数据] [生成预测] [数据管理] [下载]                    │
├──────────────────────────────┬──────────────────────────┤
│ 三维设备                     │ 当前组实测概览与历史趋势 │
├──────────────────────────────┴──────────────────────────┤
│ 当前组：历史 → 预测 → 后续实测对照（统一指标与时间选择）   │
│ 与上方历史区域共用一份图表：可扩展查看，不再绘制第二套历史 │
├──────────────────────────────┬──────────────────────────┤
│ 预测结论 / 状态 / 预警部位    │ 本次核验：误差与结论匹配 │
├──────────────────────────────┴──────────────────────────┤
│ 累计统计：已核验次数、状态准确率、结论准确率、平均误差     │
└─────────────────────────────────────────────────────────┘
```

布局示意中的时序区是右侧历史图的扩展区域，不是另一张重复图。实现时可将同一图表扩展到整行；整页每个指标只保留一份历史序列展示。

- 顶部工作栏管理整页当前选择；所有操作围绕当前设备和当前数据组。
- 三维区保留设备结构展示；历史概览显示当前组最新值，不称旧上传记录为实时遥测。
- 统一时序区以实线、预测虚线、后续实测线区分数据；图例、时间边界、预测区间清晰，尚未验证时不显示空的验证大面板。
- 预测结论包含正常/异常标签、可能故障、对应部位、趋势依据及预警时间，不显示其他组的详情。
- 核验完成后在同一组旁显示数值误差、预测与实测状态、故障匹配情况；关联到原预测时间范围。
- 累计统计为紧凑的一行概览，不设置固定组目录或全组长表。
- 数据管理在抽屉或弹窗中查看已传入数据的设备、批次、导入时间、采集范围、条数与质量，并执行选择、增加、覆盖、删除和重置。选择操作同步回主页面；管理面板不再自带第二个上传入口。
- 下载继续覆盖数据规范、各支持格式样例、预测结果和报告，使用中文模型名、设备 ID 和明确后缀。结果及当前报告必须匹配当前选择；报告可带累计统计摘要。
- 采用页面现有蓝灰色卡片、统一标题与间距，颜色用于区分实测、预测与预警；窄屏顺序排列，不新增横向长表。

## 5. 累计统计与数据变更

- 累计统计来自实际完成的核验记录，不来自预置样例数量，也不因当前选择改变而改变。
- 状态准确率 = 正常/异常判断正确的有效核验次数 ÷ 具有实际标签的有效核验次数。
- 综合结论准确率只统计具有所需实际状态与故障依据的核验；正常组比较状态，异常组同时比较状态与故障类型。显示对应有效样本数。
- 平均误差按已对齐的有效点计算逐指标 MAE、RMSE 和归一化误差；跨指标汇总使用既定归一化口径，并显示参与次数及覆盖情况，不直接平均不同单位的数值。
- 同一个预测重复导入验证文件属于更新核验，不增加统计次数。部分核验补齐后升级原记录，不能再新增一条重复记录。
- 在相同数据版本、相同参考窗口和相同算法参数上重复点击预测应复用结果，避免反复计数。
- 覆盖或删除数据后，当前展示必须更新。已有核验快照可保留为历史评估，明确关联原数据版本，不伪装成新数据的结论。
- 删除核验记录或明确重置累计统计时才移出对应统计分母；危险操作一次确认，说明影响范围。不因普通切组或新增设备清空累计结果。
- 不以 90% 为界面预设或通过调整展示结果满足目标准确率；实际导入和核验得到多少即显示多少。

## 6. 开发衔接与验收

当前 ModelDataWorkspace 具备已有设备下拉、设备新增、增量/覆盖、协议导入和预检；HydroForecastValidation 使用独立的预置工况组流程。重构应复用已有导入能力，统一数据上下文和预测快照关联，而非只隐藏两个按钮。

需将验证业务从固定 HT 组号、固定设备编号及严格 180/360 条样例约束中解耦。仍校验字段、采样时间、有效记录及足够的预测历史，但不能因为真实上传不属于样例清单而拒绝。

验收重点：

1. 页面仅一个数据传入入口、一个设备/数据组选择上下文、一份历史曲线。
2. 已有设备增加、覆盖和新设备三条导入路径均正确存储并自动定位；未成功导入不能影响旧展示。
3. 从已保存数据直接生成预测；切换组时全页同步，不重新上传、不混用旧结论。
4. 验证前后原预测不变；错设备、错时间段、部分验证及缺标签有明确处理。
5. 重复导入和重复点击不重复累计；连续核验任意数量数据组均能动态统计。
6. 空状态无 50 组占位，完成后也没有 50 行全组表；主页面只展示当前组详情及累计概览。
7. 既有样例文件继续可用，旧入库数据和验证记录迁移后可追溯；发布不得删除共享数据目录。
