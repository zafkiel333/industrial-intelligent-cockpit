# 水轮机预测验证方案与数据说明

> 日期：2026-09-09  
> 页面：`sim-visual-hydro-turbine`  
> 模型：`2326` 水轮机多工况数字孪生分析  
> 状态：已随 Release `20260909-083801` 上线并完成公网只读验收

## 1. 业务流程

每个工况组严格按时间分为两个互不重叠的窗口：

```text
180 分钟观测数据
  -> 解析六项运行指标
  -> 冻结未来 360 分钟预测、正常/异常标签、故障类型、故障部位和文字结论
  -> 上传同组紧随其后的 360 分钟实测数据
  -> 逐时间点对照数值，并核验状态与故障结论
  -> 将本组结果写入验证台账和累计指标
```

验证数据未导入前，页面不显示实际状态和实际故障。重新导入观测数据会明确提示，并清除该组旧验证结果后重新冻结预测；不会影响其他组。

## 2. 数据规模与分布

| 项目 | 数量 |
|---|---:|
| 工况组 | 50 |
| 每组观测记录 | 180 |
| 每组验证记录 | 360 |
| 观测记录总数 | 9,000 |
| 验证记录总数 | 18,000 |
| 正常组 | 27 |
| 异常组 | 23 |

异常组覆盖轴系不平衡、轴承温升异常、水力工况失稳和机组出力衰减。数据包含周期负荷变化、测量噪声、后续负荷偏移、渐进退化、弱先兆及短时恢复等情况，不以完全可分的规则制造 100% 结果。

## 3. 文件结构

观测文件固定字段：

```text
case_id,timestamp,device_id,quality,rpm,temperature,vibration,pressure,flow_rate,power_output
```

验证文件在相同字段后增加：

```text
actual_tag,actual_fault_code,actual_fault_name,actual_fault_part
```

- `case_id`：`HT-01`～`HT-50`，必须与页面所选组一致。
- `device_id`：`2326-VAL-01`～`2326-VAL-50`，一组固定对应一台记录设备。
- `timestamp`：ISO 8601，组内严格按 60 秒递增；验证段紧接观测段。
- `quality`：`good` 或 `uncertain`；明显非法值、空值和非数值被拒绝。
- `actual_tag`：`normal` 或 `abnormal`，仅验证文件允许出现。
- 异常组必须给出统一的实际故障代码；正常组故障代码为空。

六指标及参考工作区间：

| 字段 | 中文 | 单位 | 参考范围 |
|---|---|---|---:|
| `rpm` | 转速 | r/min | 140～160 |
| `temperature` | 轴承温度 | °C | 35～75 |
| `vibration` | 主轴振动 | mm/s | 0～4.5 |
| `pressure` | 水压 | MPa | 1.1～2.4 |
| `flow_rate` | 流量 | m³/s | 18～42 |
| `power_output` | 输出功率 | MW | 12～32 |

## 4. 预测和诊断

每个字段最多使用当前观测窗口内的连续有效记录。候选模型包括稳健局部水平、阻尼趋势、周期模板和周期趋势；以三个滚动起点的多步 MAE 选择非周期基线，周期候选还需达到相关性和相对改善门槛。经验预测区间由回测绝对误差分位数与短期差分噪声共同形成，并随预测距离扩展。

状态预测依据当前偏离、趋势、残差波动和未来持续越界。异常时按字段证据组合输出四类故障之一及对应部位：

| 故障类型 | 主要证据 | 预警部位 |
|---|---|---|
| 轴系不平衡风险 | 主轴振动、转速 | 主轴、联轴器与转轮 |
| 轴承温升异常 | 轴承温度、主轴振动 | 主轴承及润滑冷却回路 |
| 水力工况失稳 | 水压、流量、主轴振动 | 引水流道与导叶机构 |
| 机组出力衰减 | 输出功率、流量、转速 | 发电机及励磁系统 |

预测阶段只能读取观测文件。实际标签和后续数值只在验证阶段进入比较函数，不参与拟合、选模或故障判定。

## 5. 核验指标

- `MAE`：同一字段 360 个点的平均绝对误差。
- `RMSE`：对较大偏差更敏感的均方根误差。
- `归一化 MAE`：`MAE / (参考上限 - 参考下限)`，用于跨量纲平均。
- `SMAPE`：按预测值与实测值绝对值之和归一化的对称误差。
- `预测区间覆盖率`：实测值落入冻结预测上下界的比例。
- `状态准确率`：正常/异常标签命中组数除以已验证组数。
- `异常故障类型准确率`：实际异常组中故障类型命中的比例。
- `综合结论准确率`：状态和故障类型同时正确的组数除以已验证组数。

当前 50 组完整留出结果为：状态 96%、综合结论 94%、异常故障类型 91.3%、平均归一化 MAE 18.26%、SMAPE 20.20%、预测区间覆盖率 89.11%。这些数值用于验证实现可复现性，不替代现场数据上的模型验收。

## 7. 页面设计

- 顶部显示已完成组数、状态准确率、综合结论准确率、异常故障类型准确率、归一化误差、SMAPE 和区间覆盖率。
- 左侧固定 50 组索引，区分未开始、预测已冻结和已验证。
- 主区按“观测数据 → 冻结预测 → 后续实测”排列，避免把两个文件误当作同一次普通上传。
- 核验后显示预测状态、实际状态、预测故障、实际故障、六指标对照曲线和逐指标误差。
- 底部台账保留 50 组完整进度，点击记录回到对应组。
- 下载本组数据或 50 组数据包；单组删除和全部重置均要求一次确认。
