# 外部模型预测算法说明

> 状态：20260909 已在四页试点上线长周期预测与持续越界预警；现场数据校准和更高阶算法族尚未执行  
> 定位：按每个模型的实际应用场景设计预测与诊断逻辑；共用预处理和计算组件，但不使用一套通用字段或故障规则覆盖全部模型

## 2026-09-09 长周期预测与预警修订（本地待发布）

预测窗口按设备动态特性分别配置：水轮机和污水泵为未来 6 小时，桥式起重机为未来 30 分钟，矿卡为未来 2 小时。窗口变长不等于可靠性不变，因此页面同时展示随预测距离扩大的经验误差带，结论使用持续越界而不是单个远期点。

每字段最多使用最近 720 个连续、近似等间隔且质量非 `bad` 的记录。候选包括指数平滑形成的稳健局部水平、基于分块中位数斜率的阻尼趋势、纯周期模板及带阻尼趋势的周期模板。周期搜索为 4～180 个采样点，重复相关性不低于 0.55；三个滚动起点执行最多 60 步多步回测。周期候选的 MAE 至少比最佳非周期基线改善 8%才被选用，否则回退至更保守的平滑或阻尼趋势。

预测误差半径取所选模型滚动回测绝对误差的 90% 分位与短期一阶差分噪声下限的较大值，并按预测距离平方根扩展。该范围不是已校准置信区间；模型参考上下限不参与拟合和预测裁剪，仅用于结果筛查，非负物理量才约束下界为 0。

预警需满足同一指标预测中值连续越界，最少连续点数为 `max(3, 预测点数×1.5%)`。结果包含指标、偏高/偏低、首次越界时间、峰值时间和值、连续点数、持续分钟和设备部位。设备部位按四个模型分别配置；当前偏离、局部趋势、残差波动和未来越界共同形成风险，候选故障仍由每模型故障字段组合计算。

### 水轮机两阶段独立核验

水轮机页新增按时间留出的预测验证，不改变上述拟合和诊断方法。每组前 180 分钟只含运行字段，系统据此冻结 360 分钟预测、状态标签、故障类型及部位；随后 360 分钟验证文件才含实际标签。验证入口拒绝未先形成预测、组号不一致、时间不连续或时间轴无法完整对齐的数据，从结构上避免未来数据进入预测。

数值误差按六个字段分别计算 MAE、RMSE、SMAPE、参考工作区间归一化 MAE和预测区间覆盖率，再对字段等权汇总。状态准确率比较正常/异常标签；异常故障类型准确率只在实际异常组上计算；综合结论必须同时命中状态和故障类型。当前 50 组留出核验为状态 96%、综合结论 94%、异常故障类型 91.3%、平均归一化误差 18.26%、SMAPE 20.20%；这些是当前可复现数据集的基准结果，不等同于现场设备泛化性能。

## 2026-09-08 算法修订（本轮实现）

旧版 last + slope × step 导致所有预测呈直线；原残差带也不是正常参考范围。新版按设备/批次筛选，取最近最多 240 个连续等间隔有效点；遇 bad 质量或大于采样间隔 15% 的间距偏差时切断训练段，不足 6 点不预测。采样间隔取实际中位数。

候选为末值基线、阻尼趋势（最近 12 点最小二乘斜率、阻尼 0.9）与周期模板（最近最多 3 个周期同相位均值，并按最近周期均值调整水平）。周期搜索 4–72 个采样点，最早回测训练段须有至少 2 个周期，最近周期重复相关性须大于 0.55。

在三个按时间滚动的起点做多步回测，以 MAE 选择基线；周期模型须比最佳基线改善至少 15% 才启用。展示每个字段选中方法、周期和回测 MAE。没有可靠周期时允许平坦或衰减趋势，不添加虚构随机波动。正常上下限不参与预测值裁剪；仅对非负物理量约束下界为 0。

误差带采用所选模型回测绝对误差 90% 分位，并以相邻差波动的四分之一作下限；超过回测步长后按平方根扩大。它是经验误差范围，非正常范围、非已校准 90%/95% 置信区间。回测也是模型选择过程，展示误差不能当作独立现场评估精度。六指标分别预测，不保证机械守恒耦合；现场标签及报警限仍需校准。

方法参考：https://otexts.com/fpp3/tscv.html 和 https://otexts.com/fpp3/simple-methods.html 。后续内容包含早期规划；实现以本节为准。所有后续可视化开发必须附正常/大幅异常成对验收数据。

## 1. 输出目标

每个活动数据集产生三类结果：

1. **数据展示**：历史值、质量、缺失、异常点和数据来源；
2. **预测数据**：未来若干步的预测值、上下界和预计阈值穿越时间；
3. **诊断结果**：健康分、风险等级、候选故障、证据字段、建议和可信度。

预测结果建议结构：

```json
{
  "algorithmVersion": "hybrid-v1",
  "datasetId": "ds_example",
  "sceneId": "sim-visual-hydro-turbine",
  "modelId": 2326,
  "generatedAt": "2026-09-03T00:10:00.000Z",
  "horizonSteps": 24,
  "series": [
    {
      "timestamp": "2026-09-03T00:10:05.000Z",
      "field": "vibration",
      "predicted": 2.55,
      "lower": 2.31,
      "upper": 2.79
    }
  ],
  "diagnosis": {
    "healthScore": 82,
    "riskLevel": "attention",
    "faults": [
      {
        "code": "SHAFT_IMBALANCE",
        "label": "轴系不平衡风险",
        "riskScore": 0.42,
        "evidence": ["振动趋势上升", "转速稳定时振动残差扩大"]
      }
    ],
    "confidence": 0.61
  }
}
```

`riskScore` 是规则和统计特征形成的风险指数；未取得足够故障标签并完成校准前，不称为经过现场校准的真实故障概率。该定义对系统生成、上传和协议采集数据一致，不要求页面声明数据是否为模拟来源。

## 2. 通用处理流水线

```text
格式与身份校验
-> 时间排序、去重、时区统一
-> 单位换算和质量码过滤
-> 缺失与离群处理
-> 按固定采样周期重采样
-> 构造滚动统计和设备机理特征
-> 单变量短期预测
-> 多变量关系残差和故障规则
-> 健康分、风险等级与诊断证据
-> 结果落盘并供页面分页读取
```

预处理原则：

- `bad` 数据不参与拟合，仍保留用于质量图；
- `uncertain` 数据降权；
- 小范围短缺失允许线性插值，连续缺失超过配置阈值不预测；
- 超过物理合法范围的数据判为无效，不自动截断成正常值；
- 所有窗口只使用当前时刻之前的数据，防止未来数据泄漏；
- 上传历史数据与实时协议数据以源时间戳对齐，并保留来源优先级和冲突记录。

## 3. 共用计算组件与模型专属配置

第一版采用无需训练大模型的混合算法组件。每个模型必须在独立 `algorithm.md` 中选择组件、字段、参数、阈值、预测时长和故障组合；不能仅按设备族自动套用后发布。

### 3.1 基线与异常

- 滚动中位数作为短期基线；
- MAD（中位绝对偏差）形成稳健标准分；
- EWMA 检测缓慢漂移；
- 连续越界计数过滤单点噪声；
- 变化率和滚动标准差分别描述趋势与波动。

### 3.2 时间序列预测

- 平稳或缓慢趋势字段使用 Holt 线性趋势；
- 明显周期字段使用季节性分解或带周期项的回归；
- 数据不足时降级为最后值 + 趋势外推，并降低可信度；
- 置信区间由近期残差分布计算，不能写死为固定百分比；
- 预计阈值穿越时间只在趋势稳定且区间收敛时给出，否则显示“证据不足”。

### 3.3 健康分

对字段 `i` 计算：

```text
fieldRisk_i = boundaryRisk + trendRisk + volatilityRisk + persistenceRisk
overallRisk = sum(weight_i * fieldRisk_i) / sum(weight_i)
healthScore = round(100 * (1 - clamp(overallRisk, 0, 1)))
```

权重、风险方向和正常范围来自每个模型的 `schema.json` 与 `algorithm.md`。不得继续让所有扩展模型永久使用完全相同的六字段和等价通用故障描述。

## 4. 设备族诊断逻辑

| 配置族 | 关键派生量 | 预测与诊断逻辑 |
|---|---|---|
| 水轮发电 | 温度对功率残差、振动对转速残差、压力/流量波动、单位流量出力 | Holt 趋势 + 耦合残差；识别轴系、水力稳定、空蚀和出力衰减 |
| 泵与流体 | 压力-流量曲线偏差、单位流量功率、振动与压力联合残差 | 工况基线 + 效率退化趋势；识别气蚀、堵塞、磨损和密封风险 |
| 阀门液压 | 指令-反馈偏差、响应时间、压差-流量关系、泄漏趋势 | 阶跃响应特征 + 漂移检测；识别卡涩、内泄和执行器退化 |
| 通用旋转机械 | 振动 RMS/波动、温升、转速归一化振动、电流负载 | 稳健异常 + 趋势预测；识别不平衡、不对中、松动和轴承风险 |
| 起重启闭 | 载荷率、制动响应、位置跟踪误差、温振负荷残差 | 工况分层阈值 + 连续风险；识别超载、制动和定位问题 |
| 矿山移动设备 | 温升对负载残差、油压稳定性、振动、油耗/功率效率 | 多变量残差 + 趋势；识别动力、液压、传动和结构风险 |
| 矿物加工 | 电流对给料量残差、轴承温升、振动、粒度偏移 | EWMA + 工况相关阈值；识别堵料、过载、磨损和不平衡 |
| 船舶港航 | 油耗-航速-载荷关系、轴振、排温、姿态与海况 | 工况回归残差 + 趋势；识别推进效率、轴系和靠泊风险 |
| 电力设备 | 温升对负载残差、三相不平衡、局放、油位/泄漏、动作时间 | 热模型残差 + 变化点检测；识别绝缘、过热、泄漏和机构风险 |
| 水工结构 | 水位-渗压残差、位移趋势、应力循环、启闭负荷 | 回归残差 + 累积损伤；识别渗流、变形、疲劳和卡阻 |
| HVAC | 制冷量/功率、温压差、振动、电流、结冰指标 | 性能比趋势 + 异常检测；识别冷媒、压缩机和风机退化 |
| 机器人 | 指令-实际位置误差、关节电流/扭矩、温度、振动 | 轨迹残差 + 漂移；识别关节磨损、伺服和定位精度下降 |
| 结构视觉 | 裂纹增长率、应力循环、磨损率、检测置信度 | Paris/Miner 的简化演示配置或阈值穿越；必须声明适用假设 |
| 仪表 | 零点漂移、量程漂移、卡值、噪声和通信缺失 | 变化点 + 卡值检测 + 与冗余量关系校验 |

算法族只是复用骨架。每个模型必须单独确认字段、阈值、故障组合和建议，不能仅按模型名称自动发布。

## 5. 实时分析策略

“实时分析”定义为新记录进入规范化通道后触发增量更新，而不是在浏览器中直接跑协议驱动：

```text
Modbus/IEC 61850 适配器或文件回放
-> 数据接入队列
-> 按场景写入当前版本和原始批次
-> 更新有限窗口特征
-> 计算预测与诊断
-> 原子更新 analysis/latest.json
-> 页面订阅或轮询最新结果
```

窗口、队列和结果必须有上限。页面隐藏或切换时停止无用轮询；服务端不得为 106 个模型同时把全部历史数据读入内存。

## 6. 系统生成数据阶段的评估

没有实际数据时只验证工程正确性和已知故障注入的可检测性：

- 正常样例不应频繁误报；
- 渐进退化样例应在预设故障发生前给出趋势风险；
- 故障样例应输出匹配的候选故障和证据字段；
- 同一输入重复运行必须得到相同结果；
- 时间切分必须按先后顺序，不能随机打乱未来记录到训练段；
- 不发布“准确率 95%”一类没有真实标签验证的指标。

页面对所有来源采用相同展示。生成器中的测试期望只用于自动化验证，不传入运行时算法，也不在页面生成特殊标签。

以后取得真实数据和故障标签后，再按设备族进行回测、阈值校准、概率校准和版本化发布。真实算法版本不得覆盖原版本，应保留输入数据哈希、配置版本和结果可追溯性。

## 7. 与现有诊断引擎的关系

现有 `diagnosticEngine.ts` 可复用健康分、风险等级、故障候选和建议的输出结构，但需要扩展：

- 支持持久数据集而不只读取进程内 60 个快照；
- 区分数据来源和质量；
- 输出未来预测序列及区间；
- 支持设备族算法配置与模型级覆盖；
- 避免扩展模型字段不匹配时全部降级为同一个 `LIVE_TELEMETRY_ANOMALY`；
- 将规则风险指数与完成真实标签校准后的概率严格区分；
- 当前数据发生覆盖、增加、重置或删除时按新 `dataVersion` 重算诊断，防止旧版本状态污染。
