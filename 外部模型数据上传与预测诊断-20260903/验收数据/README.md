# 数据可视化成对验收要求

用户于 2026-09-08 明确要求：今后这类数据可视化开发必须配套一组正常数据和一组异常大幅波动数据。本要求适用于新增页面、改版、算法修改及发布验收。

- 每个涉及模型提供相同字段、单位、采样间隔和长度的正常/异常 CSV，使用不同设备 ID，避免覆盖真实或既有演示数据。
- 正常集：数值位于配置参考范围内；异常集：反复越界、明显峰谷。合成数据用于演示与回归，不能作为现场预测精度的证明。
- 验证两组的实际读数、单位、正常带、偏高/偏低文字、越界标记、历史/预测边界、误差带开关、游标与移动端。
- 预测必须通过按时间顺序的回测择优；周期波动需要证据，无可靠周期时不能为了视觉效果添加随机波形。预测值不能被正常限裁剪；不确定性范围不能称作正常范围。
- 上传/删除测试使用隔离数据目录；线上展示用独立设备，保留旧数据。

本目录包含四个试点模型，每组 240 条一分钟记录。使用 `node scripts/generate-visualization-fixtures.mjs` 从运行中 API 的模型参考字段生成，默认 API 为本地 4178，可通过 PILOT_API_BASE_URL 指定。生成器不会上传或修改服务器数据。

正常/异常判定当前依据模型参考上下限（含边界为正常），不能替代现场配置的报警阈值；数据质量不可用时状态为不可判定。
