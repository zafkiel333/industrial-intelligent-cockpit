```text
<SCENE_DATA_DIRECTORY>/model-showcase/<sceneId>__model-<modelId>/
├─ current/state.json       当前版本、规范化记录和批次清单
├─ batches/                 文件或协议接收的原始批次
├─ imports/                 尚未完成的分块上传
├─ protocol/scl/            确认导入后永久保存的 IEC 61850 SCL
└─ reference/
   ├─ README.md
   ├─ data-schema.json
   ├─ algorithm.md
   ├─ sample.csv
   ├─ sample.xlsx
   └─ sample.json
```

生产环境使用 `/nlplabProj/scene-library/shared/data/model-showcase/` 下的模型目录。该目录位于 release 之外，代码升级和回滚不会自动删除数据。

## 4. 算法实现

- 质量为 `bad` 的记录保存但不进入预测；
- 每字段最多读取最近 720 个连续有效点，以实际采样间隔生成模型专属长周期预测；
- 滚动回测比较稳健平滑、阻尼趋势和周期趋势，周期模型只有显著改善非周期基线时才启用；
- 输出预测中值和随预测距离扩展的经验误差范围，不以正常参考限裁剪预测；
- 只有持续越过参考范围才形成预警，并输出首次时间、方向、峰值、持续时间和预警部位；
- 使用正常区间偏离、趋势、残差波动和未来持续越界形成字段风险；
- 复用模型目录中的故障字段组合与处置建议，输出最多 3 个候选故障；
- 所有结果绑定当前 `dataVersion`，上传、删除或重置后重新计算。

当前概率是未经过现场故障标签校准的风险指数。取得真实历史与故障标签后才能开展现场回测、阈值和概率校准。

## 11. 协议来源文件导入改造（2026-09-07）

- 上传入口新增通用表格、Modbus、IEC 61850 三类数据来源。Modbus 和 IEC 61850 均采用 CSV/XLSX/JSON 长表，解析后进入现有统一存储、预测和诊断链路。
- Modbus 长表字段为 `timestamp`、`address`、`raw_value`、`data_type`、`byte_order`、`scale`、`offset`、`quality`；支持单寄存器值和两个 16 位寄存器组成的 32 位值。
- IEC 61850 长表字段为 `timestamp`、`ied`、`object_reference`、`functional_constraint`、`value`、`quality`；同一时间的对象点位聚合为一条完整模型记录。
- 上传流程改为“上传 -> 解析与映射预检 -> 用户确认 -> 写入”。预检阶段只保存临时规范化记录，不改变 `current/state.json`；确认后才生成批次、更新数据版本并触发预测诊断。
- 预检结果显示来源、源行数、完整记录、点位映射、时间范围、质量、重复时间、未映射点位和预计数据影响；缺少必需点位的时间组被拒绝，不进入预测。
- IEC 61850 支持可选 ICD/CID/SCD/SSD XML 文件检查，显示 IED、逻辑设备和数据对象摘要；该文件仅用于点位模型核对。
- 批次表显示数据来源；每模型参考目录新增 `modbus-sample.csv/xlsx/json` 和 `iec61850-sample.csv/xlsx/json`。
- 接口：`POST .../data/imports/:batchId/preview` 生成预检，原 `complete` 接口改为确认导入；样例下载增加 `source=modbus|iec61850`。
- 专项验证：原有下载 52 项通过，协议样例 24 项通过，两个协议均完成预检不写入、确认后写入、来源记录和删除还原；`npm run build:all`、Playwright 四页双视口和完整上传流程通过。
- 当前状态：已完成本地试点改造，尚未发布云端；真实设备直连仍需现场 Modbus 参数、IEC 61850 SCL 与通信配置，不能以本次文件接入验证替代实机验收。
