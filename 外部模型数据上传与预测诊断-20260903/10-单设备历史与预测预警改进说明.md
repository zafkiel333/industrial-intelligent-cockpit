# 单设备历史、预测与预警改进

日期：2026-09-09。适用页面：水轮机 sim-visual-hydro-turbine / 2326。

状态：已随 Release 20260909-163928 上线，并完成公网双视口、六图布局、模型加载和下载验收。

本文更新 09 号方案中的入口合并和批次选择设计。

## 操作流程

1. “导入历史数据”：选择已有设备追加/替换，或新增设备 ID。成功后设备只有一份当前历史；批次保留用于管理，不再作为另一份可选预测历史。
2. “生成预测”：以该设备当前历史为唯一参考，使用末段连续有效数据拟合。实际连续记录不足 24 条时拒绝预测。
3. “导入验证数据”：独立入口，仅核验当前保存的预测，锁定设备。验证文件按时间对齐，不改变历史、不重新拟合原预测；弹窗展示对齐条数、剔除条数及覆盖率。
4. 三维与运行指标、预测结果、预警与处置建议、实测核验及累计统计按同一设备上下文更新。

设备参考历史下拉框已移除。API 的旧 batchId 参数不再切割统一工作区的设备历史。已有预测快照和验证文件保留，更新算法不会重写旧预测。

## 预测方法

旧算法在 180 条记录时，受最早回测起点和三周期要求共同限制，只搜索约 38 个采样点以内的周期，容易遗漏 60～115 点周期，或把相邻数据相关误判成短周期。

新版为水轮机统一工作区引入“谐波回归＋AR(1) 残差”，与非周期稳健水平、阻尼趋势基线比较：

- 正弦/余弦基函数拟合周期、幅值和相位；1～2 对谐波通过 BIC 选择，并使用正则化最小二乘估计。未来点由函数外推，不复制历史片段，不加随机噪声。
- 周期粗搜和细化只读取当次训练片段；每个时间留出窗口独立拟合。连续历史最多 720 点。
- 留出最近约 20%、15%、10% 的历史，单次最长 90 点；要求至少两个窗口优于基线，总 MAE 改善超过 8%，各窗口周期比值小于 1.25，最终历史覆盖至少 1.5 个周期。
- 每个留出训练片段至少覆盖 1.25 个候选周期。少于两个完整周期属于有限证据，页面展示实际历史长度和回测跨度，不将短期回测表述为六小时验证。
- 残差 AR(1) 参数从历史估计并约束稳定范围；远期残差影响衰减。趋势阻尼控制远期漂移。
- 若未通过门槛，则使用回测支持的稳健基线；恒定输入仍预测恒定，不为美观制造波动。
- 使用历史留出误差与拟合残差分位数估计经验误差区间，随预测距离扩展。此区间不声称具备校准后的固定覆盖概率。
- 正常参考阈值仅用于风险识别，不用于把异常预测压回正常范围。

方法背景参考：[Forecasting: Principles and Practice — Dynamic harmonic regression](https://otexts.com/fpp3/dhr.html)。本项目使用上述明确列出的简化实现和验证门槛，并非完整 ARIMA 软件包。

## 页面内容

- 预测结果：六项指标同时展示为独立趋势卡，桌面端两列三行、窄屏单列；各图保留原单位和独立纵轴，共用时间轴与图例，悬停游标按时间联动。每卡展示预测范围、末点和采用方法；不需要切换指标。
- 历史、预测、后续实测在同一指标图内接续展示；正常参考带与经验误差带分别着色。长历史图按时间抽样，不改变服务端预测训练窗口。
- 预警区域：趋势状态、可能故障、重点部位；每项预警列指标、阈值、最长连续越界段开始时间、持续时间和峰值；按证据给出排查建议。
- 正常状态：显示未触发持续越界和常规检查项目，不把日常检查项目当作已发生故障。
- 核验区域：覆盖率、状态与故障结论匹配、六指标 MAE/RMSE/归一化误差和累计统计。
- 报告下载同步包含方法、回测信息、阈值预警与检查建议，与当前预测快照一致。

## 从用户与答辩评审角度核对

| 可能质疑 | 对应处理 |
|---|---|
| 同一设备为什么有多份可选历史？ | 移除批次参考选择；追加与替换产生唯一当前历史。 |
| 验证会不会覆盖历史或改写预测？ | 独立按钮、锁定设备、专用预检；对照已保存快照。 |
| 曲线是不是人为加波动？ | 谐波参数由历史估计，时间留出选模，不叠加随机值。 |
| 为什么有时仍然是平稳曲线？ | 展示所选方法与回测误差；恒定或不可稳定预测的波动由区间表达。 |
| 为什么能预测六小时，回测却只有几十分钟？ | 明示实际回测跨度和预测跨度，远期外推需后续实测核验。 |
| 预警凭什么指向某个部位？ | 展示触发指标、参考阈值、持续时间、峰值、部位关联和排查建议。 |
| 准确率能否通过反复上传或换算法刷高？ | 同一预测重复核验更新原记录；相同设备/历史跨算法版本只计最新已完成评估。 |
| 实际标签缺失是否被算作正确？ | 缺标签不进入状态准确率分母，缺故障依据不进入结论准确率分母。 |
| 更新算法会不会替换原来的证据？ | 算法版本进入预测标识，旧快照保留，原预测与核验不被重写。 |

## 回归结果

- 独立构造的非整数周期数据：谐波模型在 120 点留出上 MAE 约 0.0219，确定性复算一致；恒定输入仍保持恒定。
- 50 组既有样例重新计算：状态准确率 96%、综合结论准确率 94%、平均归一化 MAE 17.7958%。该结果仅为样例留出回归，不预填页面累计统计，也不替代现场验收。
- 新增单设备追加、替换后唯一历史检查；已有部分/完整核验、重复导入、错设备、缺标签分母、协议与多格式下载检查继续执行。
