## 1. 规划目标

为所有外部模型展示页增加统一的数据接入能力：

1. 页面提供数据上传入口；
2. 分别显示文件上传进度和服务端解析进度；
3. 一个页面固定对应一个 `sceneId`、一个 `modelId` 和一套当前数据；
4. 同一型号的不同具体设备通过 `device_id` 进入同一页面数据，导入时可选择覆盖或增加；
5. 支持覆盖、增加、重置、按范围删除和全部删除，并可视化展示已有数据概况与导入时间；
6. 将原始文件、规范化数据、预测结果和诊断结果按页面模型隔离存放；
7. 连接 Modbus 与 IEC 61850 设备，并通过统一点位模型支持双向数据转换；
8. 在没有现场数据的阶段，为每个模型提供可复现的系统生成样例；
9. 不因数据来源改变后续解析、预测、诊断和展示流程，页面不显示“模拟/仿真”标识；
10. 为每个模型配套 CSV、XLSX、JSON 样例、数据规范、算法说明及四类下载入口；
11. 不设置业务数据大小和保存期限上限，不自动删除数据；
12. 先完成 4 个页面试点，经用户最终确认后再分批推广至全部页面。

## 3. 协议范围

用户已确认第二种协议为 **IEC 61850**。规划支持 Modbus 与 IEC 61850 设备直接采集，并支持两个方向的遥测数据转换：

- Modbus TCP、RTU，现场需要时兼容 ASCII；
- IEC 61850 MMS 读取、报告、质量和源时间戳；
- 两侧数据先转换为统一点位模型，再依据版本化映射发布到目标协议；
- 第一版互转为遥测数据和值发布，不包含控制、保护动作或联锁命令；
- 真实可用性必须通过具体型号设备或厂家认可网关验收。

协议接入、转换方向、映射规则、异常处理和实机验收详见 `05-协议设备接入与互转方案.md`。

### 3.1 当前页面文件接入方式

四个试点页的上传弹窗已支持“通用表格、Modbus、IEC 61850”三类来源。两类协议文件采用固定字段长表并支持 CSV、XLSX、JSON。上传完成后先显示点位映射、时间范围、质量、明显异常分类和预计影响，用户确认后才写入并执行预测诊断。IEC 61850 的 ICD/CID/SCD/SSD/XML 可作为 SCL 点位模型；确认导入后永久保存到每个模型独立的 `protocol/scl/` 目录。

当前实现的是“设备或网关导出文件接入”和语义转换，不是 Modbus TCP/RTU 或 IEC 61850 MMS 的实时联网驱动。真实设备直连仍需现场通信参数、点表/SCL 和单独实机验收。

参考资料：

- Modbus Organization：<https://www.modbus.org/modbus-specifications>
- IEC 61850 系列：<https://webstore.iec.ch/en/publication/6028>
- IEC 61850 与 Modbus 网关映射：<https://webstore.iec.ch/en/publication/26906>
