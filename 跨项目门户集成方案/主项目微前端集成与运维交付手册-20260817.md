## 5. qiankun 协议 1.0

### 5.1 props 类型

```ts
export interface SceneLibraryHostProps {
  protocolVersion: '1.0';
  container: Element;
  viewId?: string;
  apiBase?: string;
  locale?: 'zh-CN';
  theme?: Record<string, string>;
  visible?: boolean;
  navigate?: (viewId: string, title?: string) => void;
  reportStatus?: (status: { state: string; message?: string }) => void;
}
```

### 5.2 字段行为

| 字段 | 必填 | 实际行为 |
|---|---|---|
| `protocolVersion` | 是 | 必须严格为 `'1.0'`，否则抛错 |
| `container` | 是 | 必须是 `Element`，不能是 selector 字符串 |
| `viewId` | 否 | 有效时打开指定页，无效时回退 `smart-ops` |
| `apiBase` | 否 | 主项目必须传 `/scene-library-api/` |
| `locale` | 否 | 当前仅定义 `zh-CN` |
| `theme` | 否 | 只接收键名以 `--` 开头的 CSS 变量 |
| `visible` | 否 | `false` 时只隐藏根 DOM，不承诺暂停所有 WebGL/轮询 |
| `navigate` | 否 | 子应用切页时回传 `viewId` 和标题 |
| `reportStatus` | 否 | `mount` 成功报告 `ready`，失败报告 `error` |

`apiBase` 要求：

- 以单个 `/` 开头；
- 不允许 `//`、反斜杠和完整 URL；
- 末尾缺少 `/` 时子应用会自动补齐。

### 5.3 生命周期

| 方法 | 行为 |
|---|---|
| `bootstrap()` | 一次性初始化，当前无页面副作用 |
| `mount(props)` | 校验协议和容器，创建 React 19 Root 并渲染 |
| `update(partialProps)` | 与已有 props 合并，支持更新 `viewId`、`theme`、`visible` 和 `apiBase` |
| `unmount()` | 卸载 React Root，清空子应用根节点内容和内联样式 |

同一实例不能重复 `mount`。主项目必须在离开路由时先等待 `unmount()` 完成，再删除容器 DOM。

### 5.4 挂载容器

子应用会在 `props.container` 中查找：

```html
<div data-scene-library-root></div>
```

如不存在则自动创建。宿主容器及其父级链路必须有可计算高度，并建议设置：

```css
.scene-library-host {
  display: flex;
  flex: 1;
  min-width: 0;
  min-height: 0;
  width: 100%;
  height: 100%;
  overflow: hidden;
}
```

| `cv-monitor` | 计算机视觉监测 |
| `vibration-monitor` | 震动监测 |
| `maintenance-training` | 维修培训 |

子级 ID 的代码事实源是场景库项目 `constants.tsx` 中的 `MENU_ITEMS`。主项目不复制全量列表，只保存当前 query 值。

可用于联调的子页：

```text
sim-visual-hydro-turbine
sim-visual-wastewater-pump
sim-visual-bridge-crane
sim-visual-haul-truck
eq-18
```

同步规则：

1. 首次挂载把 `route.query.view` 传为 `viewId`；
2. `navigate` 回调时主项目用 `router.replace` 更新 query；
3. 前进/后退改变 query 时调用 `update({ viewId })`；
4. 新旧 ID 相同时不再同步，防止循环；
5. query 只允许字母、数字、`-`、`_`，建议最长 128 字符。

## 10. 安全、CSP 和样式限制

### 10.1 API 认证

当前 Express API 未集成主项目 SSO 和用户权限。主项目上线前需确定：

- 页面和菜单使用主项目现有权限守卫；
- 主项目 Nginx/API 网关对该前缀执行必要的会话或白名单检查；
- 未授权用户不能直接调用上传、删除和模型刷新接口；
- 不在 URL 或 props 中传递长期 Token。

当前 `8081` 可从公网访问，正式上线建议改为私网连接，或在云安全组/防火墙中只允许主项目服务器访问。

### 10.2 Tailwind CDN

微应用 HTML 当前依赖：

```text
https://cdn.tailwindcss.com
```

主项目需检查：

- 终端网络是否可访问该 CDN；
- CSP 是否允许必要的脚本/样式加载；
- qiankun 样式隔离是否防止 Tailwind 动态样式影响宿主。

长期建议将 Tailwind 改为本地构建产物。

### 10.3 样式隔离

场景库 CSS 中存在 `:root`、`body` 和滚动条等全局选择器。必须验证主项目已有 qiankun 沙箱和样式隔离策略，并对主项目导航、表单、表格、对话框和其他微应用做回归。
