### 操作要求

1. 先只读检查，不要立即修改或覆盖文件：

   ```powershell
   git status --short
   git branch --show-current
   git remote -v
   git log -1 --oneline
   ```

2. 如果存在未提交修改，立即停止同步并向我列出文件。不要执行 `git reset --hard`、`git checkout -- <file>`、清理未跟踪文件或擅自 stash。

3. 如果工作区干净，执行安全的快进同步：

   ```powershell
   git fetch origin
   git switch main
   git pull --ff-only origin main
   git rev-parse HEAD
   ```

4. 确认最终 HEAD 严格等于：

   ```text
   89e5c73781ae12bfec94366adc884df1ea3e8e74
   ```

5. 使用仓库锁文件恢复依赖并验证两个构建：

   ```powershell
   npm ci
   npm run build:microapp
   npm run build:standalone
   ```
