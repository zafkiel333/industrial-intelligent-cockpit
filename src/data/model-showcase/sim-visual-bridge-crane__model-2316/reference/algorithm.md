# 预测与诊断算法

推荐采样间隔：10 秒。预测窗口：未来 30 分钟。

每个指标使用最近最多 720 个连续等间隔有效点，先进行稳健局部水平和抗异常斜率估计，再通过滚动起点回测比较指数平滑基线、阻尼趋势和周期趋势三类候选。周期候选要求重复相关性不低于 0.55，且多步 MAE 比非周期基线改善至少 8%；否则使用更保守的非周期模型。预测值不按正常上下限裁剪，仅约束非负物理量。误差带按滚动回测绝对误差 90% 分位和短期噪声共同估计，并随预测距离扩展，不代表已校准置信区间。质量 bad 或采样缺口会切断训练段。

预警不是由单个预测点触发：未来预测需要持续越过模型参考范围后才形成预警。系统输出首次越界时间、方向、峰值、持续点数及模型对应部位，再将当前偏离、趋势、残差和未来持续越界共同计入故障风险。参考范围用于工程筛查，不替代现场保护定值。
