# 水轮机多工况数字孪生分析 数据目录

- 页面：sim-visual-hydro-turbine
- 模型 ID：2326
- current：当前活动数据和版本
- batches：已接收的原始批次
- imports：尚未完成的分块上传与导入预检
- reference：数据规范、算法、固定协议字段说明和三格式样例
- protocol/scl：确认导入后永久保存的 IEC 61850 SCL 文件
- validation：水轮机预测验证的冻结预测、后续实测和累计结果

通用表格、Modbus 和 IEC 61850 来源文件只在解析入口不同，字段标准化后进入同一存储、展示、预测和诊断链路。SCL 文件用于辅助核对 IEC 61850 点位模型，不作为历史测量记录，但会与所属导入批次关联并永久保存。
