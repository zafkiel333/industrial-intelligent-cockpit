# 1号机组异常预测分析方法论 (Predictive Methodology)

## 预测实现原理：混合物理信息神经网络与退化模型 (PINN & Degradation Model)

针对本系统接收到的 1组“1号机组有功功率25年6月.xls” 及 16组“1号机组N#推力瓦温度202506.xls” 时序数据，异常预测不是简单的设定阈值报警，也不是盲目外推残差。

### 核心解耦算法
在处于健康状态时，推力瓦温度($T$)与有功功率($P$)之间存在着高度的线性耦合（功率增高，负载大，温度上升）。
`T(t) = T_ambient + C * P(t) + Noise`

当某块推力瓦的微观油膜发生破裂或摩擦加剧时，摩擦系数 $C$ 将不再是常量，而是随着运行时间累积形成“不可逆的退化”(Degradation)。算法通过在线计算动态摩擦回归系数（协方差解耦），当发现某块瓦的温度演化开始“脱离”当前机组的有功功率应有表现时，即判定为进入**磨损异常通道**。然后使用带时间衰减因子的指数退化模型预测未来温度走向。

## 数据样例对照

### 1. 预测出【异常】的数据样例（特征：解耦与指数上升）
在这种情形下，机组功率并未显著提升，但特定推力瓦的温度持续上升，暴露出机械摩擦恶化。
```json
{
  "timestamp": "2025-07-15T12:00:00Z",
  "activePower": 240.5,
  "pads": [
    {"id": 1, "temp": 52.3},
    {"id": 2, "temp": 52.1},
    {"id": 3, "temp": 68.4}, // 【异常】严重偏离均值，且相对于240MW的功率过高
    {"id": 4, "temp": 64.2}, // 【异常】相邻瓦片受连带热传导影响
    // ...
    {"id": 16, "temp": 53.0}
  ],
  "prediction": "WARNING_TREND",
  "estimatedTimeOfFailure": "2025-07-18"
}
```

### 2. 预测出【正常】的数据样例（特征：功率与温度高度耦合）
在正常情形下，推力瓦温度严格跟随有功功率（日夜调峰）同频波动。
```json
{
  "timestamp": "2025-07-15T12:00:00Z",
  "activePower": 240.5,
  "pads": [
    {"id": 1, "temp": 52.3},
    {"id": 2, "temp": 52.5},
    {"id": 3, "temp": 52.4}, 
    {"id": 4, "temp": 52.6}, 
    // ...
    {"id": 16, "temp": 52.2}
  ],
  "prediction": "HEALTHY",
  "estimatedTimeOfFailure": "N/A"
}
```
该推演逻辑确保所有的风险捕获均有严密的数理和物理依托。
