### [2026-08-21] 1号机组 3D 检视与时间轴浮层浅色化

- 发布状态：Release `20260821-084944` 已上线，回滚版本为 `20260820-201251`；
- 二次反馈：首版发布后深色块仍存在，并出现浅色层与旧深色层叠加的观感；“当前检视”标签、时间轴说明等文字仍可能因颜色继承而不可见；
- 二次根因：JSX 仍保留旧 `unit1-predictive-hud`、`bg-slate-900/80`、`bg-slate-900/90` 及多组浅字工具类，CSS 中也存在三代针对旧 HUD 的深浅规则，形成竞争；
- 二次整改：从组件中删除全部旧 HUD、深色背景、深色边框和浅字工具类；移除 CSS 中所有 `.unit1-predictive-hud` 历史规则；标签、时间、说明、计数、历史起点、当前计算和预测终点均改用独立语义类；
- 防漏措施：浅色面板改为完全不透明单层 `#f1f7fa`，面板及全部后代先强制深色、不透明、正常混合，再对历史蓝和预测琥珀做深色状态区分，覆盖原先因颜色“隐身”的文字；
- 问题：3D 视窗左上“当前检视”和底部时间轴仍显示深蓝黑底，受全局主题与历史 HUD 规则叠加影响，部分文字也呈深色，造成深底深字；
- 修改：为两个浮层分别增加 `unit1-predictive-inspection-panel`、`unit1-predictive-timeline-panel` 专用类，并为计数标签增加明确的数据状态；
- 配色：浮层统一为略带冷蓝的半透明浅灰白 `rgba(241, 247, 250, 0.96)`，正文使用深蓝灰 `#20384a`，配柔和蓝灰边框与轻量阴影；
- 状态：历史时间使用深蓝色和淡蓝底，预测时间使用深琥珀色和淡暖白底，保留状态区分但避免突兀；
- 稳定性：最终规则放在主题样式文件末尾并使用页面专用作用域，避免旧深色 HUD 或 Canvas 通用规则再次覆盖；
- 影响范围：只调整一号机组页面这两个浮层及其时间轴控件，不改变 3D 模型、数据、预测算法、上传、布局、路由或其他页面。
- 验证：专项类型检查、导航检查、HTTPS 集成检查和双构建通过；3103 生产等价预检通过；现网独立/嵌入入口、microapp 与健康接口均为 200；公开 CSS 已命中新专用类和颜色值；
- 目视边界：当前无可连接浏览器实例，未执行发布后的截图级目视复核，需用户刷新页面后确认最终视觉效果。
