## 8. 场景库页面

场景库既要支持数据规模和覆盖率核查，也要支持“20 类场景存在、独立展示页可打开、故障数据接入、诊断预警和三维定位 5 秒闭环”。

### 8.1 场景库总览与分类页开发清单

| 页面区块 | 具体页面功能 | 必须展示/操作的内容 | 建议接口 | 测试怎么验 |
|---|---|---|---|---|
| 场景数量统计 | 展示场景总数和按行业/分类统计数量。 | `N_scene`、行业数量、分类数量、更新时间。 | `GET /api/scenario-lib/summary` | 支撑场景库总量核查。 |
| 20 类目录 | 展示任务书明文规定的 20 类场景，并显示每类数量。 | 场景分类名称、分类编码、场景数量、是否已配置页面。 | `GET /api/scenario-lib/categories` | 支撑 20 类场景存在性核查。 |
| 场景列表 | 支持按分类、行业、设备、状态、关键词筛选。 | 场景 ID、名称、分类、行业、关联设备、页面状态、更新时间。 | `GET /api/scenarios` | 支撑随机抽查 5 个场景。 |
| 分页与跳页 | 支持记录每页条数、总条数、总页数、跳页加载状态。 | `N_per_page`、`N_list`、`P_total`、当前页、首尾场景 ID。 | `GET /api/scenarios?page=&pageSize=` | 支撑分页核查。 |
| 场景导出 | 导出全量场景明细和分类映射。 | 场景 ID、名称、分类、行业、关联设备、关联模型、页面地址。 | `GET /api/scenarios/export` | 支撑场景覆盖率计算。 |
| 覆盖率核查 | 页面可导入或选择标准业务场景清单，计算覆盖率。 | `S_total`、`S_covered`、覆盖率、未覆盖原因。 | `GET /api/scenario-coverage` | 支撑 70%-90% 场景覆盖率。 |

### 8.3 场景详情页开发清单

| 页面区块 | 具体页面功能 | 必须展示/操作的内容 | 建议接口 | 测试怎么验 |
|---|---|---|---|---|
| 场景基础信息 | 展示场景身份、分类、行业和业务目标。 | 场景 ID、名称、分类、行业、适用设备、业务目标、状态。 | `GET /api/scenarios/{scenarioId}` | 随机抽查场景并打开详情。 |
| 标准场景映射 | 展示该场景覆盖哪个标准业务场景清单条目。 | 标准清单名称、标准类目编码、类目名称、覆盖状态、未覆盖说明。 | `GET /api/scenarios/{scenarioId}/coverage-mapping` | 支撑场景覆盖率核查。 |
| 关联模型区 | 展示该场景调用的组件、设备、指标、可视化模型。 | 模型 ID、名称、类型、用途、跳转链接。 | `GET /api/scenarios/{scenarioId}/models` | 支撑模型库与场景库联动。 |
| 页面配置区 | 展示该场景是否已配置独立展示页和页面元素。 | 页面地址、布局 ID、组件分布区、状态仪表区、三维视图区、预警区。 | `GET /api/scenarios/{scenarioId}/layout` | 支撑“独立展示页面”核查。 |
| 工作流区 | 展示场景从数据接入到诊断预警的流程。 | 接收数据、解析识别、模型判断、故障定位、预警生成、前端渲染。 | `GET /api/scenarios/{scenarioId}/workflow` | 支撑工作流贯通验证。 |
| 网关配置区 | 展示或复制测试网关地址、端口、协议和数据格式。 | 网关地址、监听端口、协议类型、字段映射、样例数据包。 | `GET /api/scenarios/{scenarioId}/gateway-config` | 支撑模拟工具发送故障特征数据包。 |
| 测试入口 | 提供“发送测试数据包”“触发诊断”按钮。 | 测试编号、样例故障数据、发送按钮、诊断按钮。 | `POST /api/scenarios/{scenarioId}/test-data`、`POST /api/scenarios/{scenarioId}/diagnose` | 支撑端到端闭环测试。 |

### 8.4 场景独立展示页开发清单

这是测试人员随机点击进入后真正看的页面，必须高保真、可触发、可记录。

| 页面区块 | 具体页面功能 | 必须展示/操作的内容 | 建议接口 | 测试怎么验 |
|---|---|---|---|---|
| 场景标题与状态 | 展示当前场景名称、设备、行业、运行状态。 | 场景名称、设备名称、在线状态、最近数据时间。 | `GET /api/scenarios/{scenarioId}/runtime-status` | 确认进入的是独立场景页面。 |
| 特定组件分布 | 展示该场景涉及的设备组件分布。 | 组件名称、组件位置、组件状态、异常标识。 | `GET /api/scenarios/{scenarioId}/component-layout` | 支撑原文“包含特定组件分布”。 |
| 状态监测仪表 | 展示关键运行指标。 | 转速、温度、振动、电压、寿命状态、告警状态等。 | `GET /api/scenarios/{scenarioId}/metrics` | 支撑原文“状态监测仪表”。 |
| 三维设备视图 | 展示设备或场景三维视图。 | 3D 模型、部件层级、故障位置标记、视角控制。 | `GET /api/scenarios/{scenarioId}/3d-view` | 支撑故障三维空间定位。 |
| 故障数据接收状态 | 显示测试数据包是否被接收。 | 数据包 ID、接收时间 `T_start`、协议、解析状态。 | `GET /api/scenarios/{scenarioId}/ingestion-status` | 支撑“系统能成功接收并解析数据”。 |
| 解析与诊断过程 | 显示数据解析、异常识别、模型诊断进度。 | 解析完成时间、异常特征、诊断模型、诊断状态。 | `GET /api/scenarios/{scenarioId}/diagnosis-progress` | 支撑从异常捕获到预警的流程证明。 |
| 故障诊断结果 | 显示诊断结论和预警信息。 | 故障类型、故障位置、预警等级、诊断预警信息、处置建议。 | `GET /api/scenarios/{scenarioId}/diagnosis-results` | 支撑显示故障诊断结果。 |
| 三维定位高亮 | 在三维视图中高亮故障部件或空间位置。 | 故障部件 ID、三维坐标、颜色、闪烁/标注状态。 | `POST /api/scenarios/{scenarioId}/3d-highlight` | 支撑“故障位置可视化显示”。 |
| 端到端耗时面板 | 展示从接收测试数据到前端渲染完成的全流程时间。 | `T_start`、解析时间、诊断时间、渲染完成 `T_end`、`T_diag`、是否 `<=5s`。 | `GET /api/scenarios/{scenarioId}/e2e-logs` | 支撑 5 秒闭环指标。 |
| 场景日志 | 支持查看、复制、导出本次测试日志。 | 测试编号、日志级别、时间戳、模块、内容、结果。 | `GET /api/scenarios/{scenarioId}/e2e-logs` | 支撑测试记录和问题追溯。 |

### 8.5 场景库页面要支持的接口

| 接口 | 输入 | 输出 | 页面用途 |
|---|---|---|---|
| `GET /api/scenario-lib/summary` | 无 | 场景总数、分类数量、行业分布 | 场景库总览页。 |
| `GET /api/scenario-lib/categories` | 无 | 20 类场景目录和数量 | 20 类目录。 |
| `GET /api/scenarios` | 分页、分类、行业、设备、关键词 | 场景列表、总条数、总页数 | 场景列表页。 |
| `GET /api/scenarios/export` | 筛选条件 | 场景明细文件 | 场景导出。 |
| `GET /api/scenario-coverage` | 行业、标准清单 | 覆盖率、覆盖/未覆盖条目 | 覆盖率核查。 |
| `GET /api/scenarios/{scenarioId}` | 场景 ID | 场景基础信息 | 场景详情页。 |
| `GET /api/scenarios/{scenarioId}/models` | 场景 ID | 四类关联模型 | 关联模型区。 |
| `GET /api/scenarios/{scenarioId}/layout` | 场景 ID | 独立页面布局配置 | 页面配置区。 |
| `GET /api/scenarios/{scenarioId}/gateway-config` | 场景 ID | 网关地址、端口、协议、样例数据 | 网关配置区。 |
| `POST /api/scenarios/{scenarioId}/test-data` | 测试编号、故障特征数据包 | 接收时间、解析状态 | 测试入口。 |
| `POST /api/scenarios/{scenarioId}/diagnose` | 测试编号、数据包 ID | 诊断任务 ID、诊断状态 | 触发诊断。 |
| `GET /api/scenarios/{scenarioId}/diagnosis-results` | 测试编号 | 故障类型、位置、预警等级、处置建议 | 故障诊断结果区。 |
| `GET /api/scenarios/{scenarioId}/e2e-logs` | 测试编号 | 全流程时间戳和日志 | 端到端耗时面板。 |

## 9. 公共测试支撑

这些功能不属于某一类模型或场景，但 5.5 测试几乎都会用到。

| 功能 | 页面/接口要求 | 支撑测试 |
|---|---|---|
| 测试会话 | 创建测试编号，贯穿数据注入、仿真、评估、渲染、日志导出。接口：`POST /api/test/session`。 | 避免测试记录分散。 |
| 高精度时间戳 | 所有关键动作都记录开始和结束时间，至少到毫秒级。 | 支撑 `T_delay`、`T_vis`、`T_eval`、`T_diag`。 |
| 日志检索 | 按测试编号、模型 ID、场景 ID、时间范围查询日志。接口：`GET /api/test/session/{testId}/logs`。 | 支撑测试记录和问题追溯。 |
| 记录导出 | 导出模型总量、覆盖率、仿真、可视化交互、指标预警、场景闭环测试记录。接口：`GET /api/test/session/{testId}/export`。 | 支撑第三方测试报告。 |
| 稳定性日志 | 查询长周期运行、OOM、宕机、异常错误码。接口：`GET /api/system/stability-logs`。 | 支撑连续稳定无崩溃证明。 |
| 测试账号权限 | 管理员账号能访问统计、导出、模型详情、场景详情、网关配置、日志。 | 支撑测试条件中“具备全局统计与后台数据导出权限”。 |
