## 2026-08-20：方案建立

状态：**已规划，尚未修改业务代码，尚未部署。**

### 新需求

- 场景库不再在主平台 iframe 中显示自己的全局导航栏；
- 主平台负责场景库全部菜单导航；
- 主平台关于本项目只有一个一级菜单“场景库”；
- 场景库现有菜单树整体放到“场景库”之下；
- 原场景库根菜单成为主平台二级菜单；
- 原 children 继续成为三级或更深层菜单；
- iframe 只显示导航栏以外的业务内容。

### 方案决定

- 保持当前 iframe 集成；
- 不采用 qiankun；
- 第一版使用 `embedded=1&viewId=...` URL 参数；
- 主平台路由采用 `/scene-library?viewId=...`；
- 场景库无参数独立入口继续保留原导航；
- 不新增主平台到场景库的实时切页 `postMessage`；
- 现有场景库到主平台模型详情的消息协议保持不变；
- 菜单清单由 `MENU_ITEMS` 自动生成 JSON，避免人工录入；
- 场景库先发布，主平台后发布；
- 不改变场景库 Nginx、systemd、API 前缀和 release 目录。

### 新增文档

- `00-方案总览与文档交付清单.md`；
- `01-开发计划与责任分工.md`；
- `02-场景库端开发调整指导.md`；

- `05-双平台部署联调验收与回滚说明.md`；
- `06-修改日志.md`。

## 2026-08-20：场景库端导航拆分开发完成

状态：**已开发，尚未部署，尚未进行主平台联合验收。**

### 已完成代码

- 新增独立入口参数解析：只接受 `embedded=1` 进入嵌入模式；
- 新增 `viewId` 长度、字符和菜单存在性校验；
- 未知、重复或恶意格式 ID 回退 `smart-ops`，不进入任意模块加载；
- `App` 嵌入模式不再渲染 `Sidebar`；
- 独立访问仍保留 Sidebar 和顶部栏；
- 统一导出递归菜单查找方法；
- 新增机器可读菜单 manifest 生成器；
- 新增导航协议和 20 个根菜单结构验证脚本；
- 新增本次导航相关文件的独立 TypeScript 门禁。

## 维护规则

1. 每次代码、菜单、协议或部署变化都增加一条，不覆盖旧记录；
2. 记录事实和版本，不只写“已修改”；
3. 尚未部署时明确写“未部署”；
4. 场景库与主平台版本必须成对记录；
5. 菜单变化记录 `menuVersion` 和 SHA-256；
6. 回滚也必须记录原因、目标和结果；
7. 密码、私钥、Token 和完整生产环境变量不得写入日志。
