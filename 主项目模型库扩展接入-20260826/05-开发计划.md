> 计划版本：v1.0（99 页扩展与菜单重排实施归档版）
> 首版日期：2026-08-26  
> 扩展日期：2026-08-27  
> 前置输入：[`04-页面与模型配对方案.md`](./04-页面与模型配对方案.md)、[`06-栏目排序调整方案.md`](./06-栏目排序调整方案.md)

## 1. 推荐实现方式

保留现有菜单 `viewId`，将入选入口的内容统一收敛为本轮新开发的 3D 模型页面：

```text
既有页面 viewId
    -> pageModelBindings（固定页面—模型映射）
    -> 场景库 BFF（固定 ID 白名单、文件大小/格式校验、缓存）
    -> 主项目通用模型 API
    -> Three.js 模型加载与自适应取景
    -> 经过筛选的业务指标语义 + Dashboard 数据 + 场景/诊断/报告
```

模型绑定入口不再展示旧业务页面，也不提供“模型展示 / 原业务页”切换。旧页面中与实际模型一致的指标、趋势和说明可在审核后融合进新页面配置。这样可以：

- 保留可取的业务语义和主平台 `viewId`，同时只向用户呈现一套新页面；
- 复用前四页的可靠加载链路；
- 99 个配对中仅新增 `eq-unit1-model` 一个独立页面，其余复用现有页面，避免复制实现；
- `eq-18` 完全冻结，新增一号机组模型页不读取或改写它的数据与组件；
- 主项目模型 API 无需改造；若宿主列表需要同步新页面和排序，则重新交付菜单 manifest。

## 3. 批次验收门槛

每一批进入下一批前必须同时满足：

1. 模型 ID、名称和页面标题与配对表一致；
2. FBX 下载经过 BFF，前端不接触任意对象存储 key；
3. 文件大小、格式、超时、取消和错误提示有效；
4. 模型自动居中、缩放合理、无明显穿模，浅色模型在深色场景中可辨识；
5. 页面切换后请求和动画正确清理，不残留定时器或 WebGL 资源；
6. Dashboard 轮询、场景切换、诊断、报告和一致性功能不回归；
7. 模拟数据来源有明确标识，不写成真实 PLC/生产数据；
8. `embedded=1&viewId=<id>` 可直接打开，且不破坏现有主平台 iframe 集成；
9. 桌面常用分辨率和窄屏无关键按钮遮挡；
10. `npm` 构建、类型检查、专项验证和本轮新增验证脚本全部通过。
11. `eq-18` 始终位于工业智能运维第 19 位且功能无变化，`eq-unit1-model` 位于第 20 位；仿真分析前四页仍位于第 1～4 位。
12. 各栏目模型页形成连续前置区，未接入页面无丢失、无重复且保持原相对顺序。

## 4. 技术改造要点

### 4.1 配置层

- 新增单一事实源 `pageModelBindings`，包含 `viewId`、`modelId`、展示名称、行业、单位、主题色、默认相机、灯光、场景和是否允许资源详情跳转；不包含 `eq-18`。
- `ModelShowcaseSceneId` 不再手写 4 个字符串联合类型，改由绑定配置推导或使用受校验的标识类型。
- BFF 的模型允许列表从同一配置生成，避免前后端名单漂移。

### 4.2 展示层

- 从既有 `RemoteModelSimulationView` 中提取可嵌入式模型区和遥测控制区；原四页保持兼容。
- 支持模型级相机、缩放、旋转速度、背景、边缘线和灯光覆盖，解决缩略图中浅色模型对比不足的问题。
- 对训练/视觉监测页面支持静态热点与说明层；只有模型实际存在可分离部件时才允许部件动画。

### 4.3 数据与安全层

- 继续使用固定模型 ID 查询基本信息、文件、AI 元数据和 Dashboard。
- 默认 50 MiB 硬限制不放宽；如 Phase 0 发现个别模型需要上调，单独提交性能证据后再决定。
- 缓存键包含模型 ID 与上游更新时间；切换模型时取消旧请求，避免大文件并发占用。
- 资源详情跳转默认关闭，确保 99 个配对 ID 不依赖主平台宿主白名单。

## 5. 测试矩阵

| 维度 | 最少覆盖 |
|---|---|
| 模型体量 | 小于 1 MiB、1～10 MiB、10～30 MiB |
| 形态 | 单体设备、长条/高塔、整机车辆、整船、场景型模型 |
| 材质 | 有色材质、灰白材质、贴图缺失降级 |
| 页面类型 | 运维、预测、计划、仿真、视觉监测、震动监测、培训 |
| 运行模式 | standalone、`embedded=1` iframe、直接 `viewId` 定位 |
| 异常 | 上游超时、文件 404、格式不支持、超过上限、解析失败、快速切页取消 |
| 回归 | 既有四模型页面、未接入页面、`eq-18`、菜单清单、构建产物、HTTPS 混合内容、旧业务页入口不存在 |

## 6. 里程碑与确认点

1. **M0 清单冻结**：用户确认 99 个配对、A/B/C 优先级、独立一号机组模型页和栏目排序方案；
2. **M1 兼容性复核**：提交 99 个模型实际加载结果，失败模型回到候选池替换；
3. **M2 核心演示**：先完成 6 个典型核心页，确认 3D 与原页面融合方式；
4. **M3 A 级完成**：23 页完成并回归，同时证明 `eq-18` 零改动；
5. **M4 B 级完成**：57 页按 5～7 个增量批次交付；
6. **M5 C 级完成**：19 页逐项确认主题收敛和指标删改；
7. **M6 发布候选**：完成全量构建、文档、发布包和回滚材料，另行取得部署授权后再上线。

## 7. 本轮不做事项

- 不修改主项目 API；
- 不向主项目写入模型、场景或配置；
- 不一次性为 1,140 个模型生成页面；
- 不为暂缓的 6 个页面使用牵强替代模型；
- 不修改、迁移或复用 `eq-18` 的独立数据展示页面；
- 不移动 `eq-18` 和仿真分析前四页的受保护位置；
- 不在用户确认前修改业务源码、构建产物或服务器。
